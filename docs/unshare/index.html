Unshare.

Every Dropbox shared link you own, in one list. Tick what you don't need and revoke in bulk. Your token stays in this tab only; nothing is saved or sent anywhere but Dropbox.

How to get a token (2 min)
  1. Go to dropbox.com/developers/apps → Create app → Scoped access → Full Dropbox → any name (e.g. unshare-links).
  2. Open the Permissions tab, tick sharing.read and sharing.write, then Submit. Do this before generating the token.
  3. Back on Settings, under OAuth 2 → Generated access token, click Generate and paste it above. It expires after ~4 hours.
  4. When you're done, delete the app on that page to kill the token.
